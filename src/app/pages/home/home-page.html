Ashen UI

A production-grade Angular component library built for dense, professional desktop applications. Three themes - light, dark, glass - via CSS custom properties. No zone.js.

Getting started

Install the package, import the styles, use your first component.

Theming

Two-tier CSS variable system. Switch themes at runtime via data-theme.

Configuration

Application-wide component defaults, motion policy, validation display, and translation.

Design principles

  • CSS variables all the way down. Zero hardcoded values in component CSS - every color, radius, and spacing resolves through a --sn-* custom property.
  • Composable, not prop-driven. Complex components expose sub-components rather than configuration objects. Omit a sub-component from the template and its region simply does not render.
  • Directive-first. button[snButton], input[snInputText] - native semantics, accessibility, and SEO for free.
  • Angular 20+ idioms. Signals, input()/output()/model(), OnPush, zoneless change detection.
