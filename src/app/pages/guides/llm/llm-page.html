LLM documentation

Ashen UI exposes its guides and component references as Markdown for language models, search tools, and documentation workflows.

Published Markdown

Append .md to any component or guide route to receive its generated Markdown. For example, /components/button.md and /guides/theming.md return the same examples, API facts, theming tokens, and accessibility notes as the interactive page.

/llms.txt is the grouped index. /llms-full.txt concatenates every generated guide and component page for tools that accept a single source document.

Use the documentation

curl https://docs.example.com/llms.txt
curl https://docs.example.com/components/button.md

Set DOCS_SITE_URL in production builds so the index uses canonical absolute links. Static hosting must serve .md files before an application fallback rewrites the request to the Angular shell.

Source guarantees

  • Example HTML is extracted from the live demo markup.
  • Selectors, inputs, models, outputs, tokens, and built-in text defaults are generated from library source.
  • pnpm docs:check rejects stale generated API and example artifacts before Markdown is emitted.
