Getting started

Install Ashen UI and add your first component in under five minutes.

Installation

Install the package and its peer dependency (@angular/cdk) using your package manager:

pnpm add ashen-ui @angular/cdk

Import the styles

Add the design tokens to your app's global stylesheet. If you use Tailwind CSS 4, also import the theme integration file. 

/* src/styles.css */
@import "tailwindcss";                        /* optional, only if you use Tailwind */
@import "ashen-ui/styles/index.css";          /* design tokens + base styles */
@import "ashen-ui/styles/tailwind.css";       /* optional Tailwind theme vars */

For the icon font (Material Symbols Outlined) to load correctly, import ashen-ui/styles/tokens/fonts.css. This file's @font-face references ashen-ui/styles/fonts/material-symbols-outlined.woff2 - make sure your bundler resolves paths from node_modules.

Configure the app

Ashen UI requires Angular's zoneless change detection (Angular 19+):

// app.config.ts
import { provideZonelessChangeDetection } from '@angular/core';

export const appConfig: ApplicationConfig = {
  providers: [
    provideZonelessChangeDetection(),
    // …
  ]
};

Use a component

Each component is a secondary entry point. Import exactly what you need:

import { Button } from 'ashen-ui/button';

@Component({
  imports: [Button],
  template: `<button snButton>Save</button>`,
})
export class MyComponent {}
