Menubar

Horizontal application menu bar. Top-level items open dropdown submenus below them. Implements the WAI-ARIA Menubar pattern with roving tabindex, hover-open mode, and full keyboard navigation (ArrowLeft/Right across items, ArrowDown into the submenu, Escape to close).

Accessibility

Implements the WAI-ARIA Menubar pattern .

  • sn-menubar has role="menubar".
  • Each top-level item button has role="menuitem", aria-haspopup="menu" (when it has a submenu), aria-expanded, and aria-controls pointing to the open panel.
  • Only one item at a time has tabindex="0" (roving tabindex managed by FocusKeyManager with horizontal orientation and wrap).
  • While a submenu is open, ArrowLeft/Right closes it and moves to the adjacent top-level item (opening that item's submenu if it has one).
  • Submenu keyboard behavior (ArrowDown/Up, Home, End, Enter, Space, Escape, typeahead) is identical to the standalone sn-menu component.
