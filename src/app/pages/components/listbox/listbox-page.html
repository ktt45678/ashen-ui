Listbox

An always-visible option list supporting single and multiple selection. Consumer-projected <sn-list-option> children via @for. Implements ControlValueAccessor for reactive forms and ngModel. Keyboard navigation follows the WAI-ARIA APG Listbox pattern with roving tabindex and typeahead.

API

Accessibility

  • The container has role="listbox". When multiple=true, aria-multiselectable="true" is set. When disabled, aria-disabled="true" is set.
  • Each option has role="option" with aria-selected reflecting its selection state and aria-disabled when disabled.
  • Navigation uses roving tabindex - the first selected (or first enabled) option carries tabindex="0"; all others have tabindex="-1".
  • Arrow keys move focus between options; Home/End jump to first/last. Arrow keys do not wrap (APG Listbox pattern).
  • Enter and Space activate the focused option. Space prevents page scrolling.
  • Typeahead: typing characters focuses the first matching option.
  • Disabled options are skipped during keyboard navigation and cannot be activated.
  • Provide an accessible name via ariaLabel or ariaLabelledby when no visible label is present.
  • Implements ControlValueAccessor - the disabled state propagates from bound FormControl.disable() calls.
