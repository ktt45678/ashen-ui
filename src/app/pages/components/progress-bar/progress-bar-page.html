Progress Bar

Process status bar - 8px pill track with determinate fill and % readout, or a sliding indeterminate segment. A variant="material" option renders the Material 3 style with a gapped track and stop dot.

Accessibility

  • The track element carries role="progressbar" with aria-valuemin="0" and aria-valuemax="100".
  • In determinate mode, aria-valuenow is set to the clamped value. In indeterminate mode, aria-valuenow is omitted per WAI-ARIA guidance.
  • The visible percentage label is marked aria-hidden="true" so screen readers rely on aria-valuenow rather than parsing the text.
  • Animations are disabled when prefers-reduced-motion: reduce is set.
