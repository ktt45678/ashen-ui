Tree Select

A Select-style trigger that opens the sn-tree component in a floating panel. Parent nodes expand and collapse - only leaf nodes are selectable and close the panel. Follows the WAI-ARIA combobox + tree popup pattern. Implements ControlValueAccessor for reactive forms and ngModel.

API

Accessibility

  • Trigger has role="combobox", aria-haspopup="tree", aria-expanded, and aria-controls pointing to the panel id.
  • On open, focus moves into the embedded sn-tree (first treeitem with tabindex="0") so full tree keyboard navigation is immediately available.
  • Parent row click - toggles expansion only. The value is not changed and the panel stays open. The one-way [selectedKey] binding on the tree re-asserts the parent's value on the next change-detection cycle.
  • Leaf row click / Enter on leaf - sets the value, emits (nodeSelect), and closes the panel with the 120 ms animation.
  • Escape - closes the panel without changing the value and returns focus to the trigger.
  • Tab - closes the panel and moves focus naturally to the next focusable element.
  • Trigger closed: Enter, Space, ArrowDown, ArrowUp all open the panel.
  • Full APG TreeView keyboard (ArrowDown/Up/Left/Right, Home/End, Enter/Space) is provided by the embedded sn-tree component.
  • When used inside <sn-form-field>, the trigger receives the field's controlId and reports filled/unfilled state.
  • Implements ControlValueAccessor - disabled state propagates from FormControl.disable().
