Select

An input-styled trigger that opens a floating option panel. Implements the WAI-ARIA APG Select-Only Combobox pattern - focus stays on the trigger while aria-activedescendant tracks the highlighted option. Consumer-projected <sn-list-option> children (shared from ashen-ui/listbox). Implements ControlValueAccessor for reactive forms and ngModel.

API

Accessibility

  • Follows the WAI-ARIA APG Select-Only Combobox pattern.
  • The trigger button has role="combobox", aria-haspopup="listbox", aria-expanded, and aria-controls pointing to the panel id.
  • Focus stays on the trigger while the panel is open. The highlighted option is communicated via aria-activedescendant on the trigger, pointing to the option's id.
  • The panel has role="listbox". Each option has role="option", aria-selected, and aria-disabled when applicable.
  • Keyboard - trigger closed: Enter, Space, ArrowDown, ArrowUp, Home, End all open the panel.
  • Keyboard - panel open: ArrowDown/Up move the active descendant; Home/End jump to first/last; Enter/Space select the active option and close; Escape closes without change; Tab closes and moves focus naturally.
  • Typeahead: typing characters while the panel is open highlights the first matching option.
  • Disabled options have aria-disabled="true" and are skipped by the key manager.
  • The clear action is a labelled button. Pointer activation is isolated from the trigger, clearing does not open the panel, and focus returns to the combobox trigger.
  • When used inside <sn-form-field>, the trigger receives the form field's controlId (so the label's for attribute connects correctly) and reports filled/unfilled state to the field.
  • Implements ControlValueAccessor - disabled state propagates from FormControl.disable().
