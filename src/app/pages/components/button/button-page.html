Button

12px radius, 14px medium text, semantic color variants. Hover darkens one step, press darkens two. Applied to native <button> or <a> elements via the snButton attribute.

Accessibility

  • Uses native <button> and <a> semantics - no ARIA role required.
  • The disabled attribute is reflected to the native element so browsers block interaction and screen readers announce the state.
  • When loading, aria-busy="true" is set so screen readers can convey the pending state.
  • For an icon variant, always provide aria-label on the <button> element for an accessible name.
  • Focus ring uses --sn-focus-ring-* tokens and is visible only for keyboard navigation (:focus-visible).
