Context Menu

Right-click menu panel that opens at the pointer coordinates on a contextmenu event. Full APG Menu keyboard navigation with typeahead, backdrop click, Escape, and Tab to close. Reposition on repeated right-click. Reuses the existing sn-menu, snMenuItem, and sn-menu-separator components.

API

Behavior

TriggerAction
Right-click (contextmenu event)Open menu at pointer coordinates
Right-click again (menu open)Close existing menu and reopen at new coordinates (no duplicate panels)
Click on backdropClose menu
EscapeClose menu; return focus to trigger element
TabClose menu; move focus to next focusable element in page
↓ / ↑ (in menu)Focus next/previous item (wraps)
Home / EndFocus first/last item
Printable characterTypeahead: jump to next item whose label starts with that character
Enter / Space (on item)Activate item; close menu

Accessibility

Context menus implement the same WAI-ARIA Menu Button and Menu patterns as regular menus, with focus management adapted for context activation.

  • The trigger element receives aria-haspopup="menu", aria-expanded, and aria-controls pointing to the panel.
  • The overlay panel has role="menu". Each item has role="menuitem" and tabindex="-1"; focus is managed by FocusKeyManager (roving tabindex, not tab stops).
  • Disabled items set disabled and aria-disabled="true"; they are skipped by keyboard navigation and typeahead.
  • Separators have role="separator" and aria-orientation="horizontal".
  • Focus returns to the trigger element when the menu closes via Escape or backdrop click.
