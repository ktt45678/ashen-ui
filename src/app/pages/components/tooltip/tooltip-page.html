Tooltip

An advisory text bubble shown on hover and keyboard focus. Attaches to any trigger element via the [snTooltip] directive. The bubble is hoverable - the cursor can move onto it without closing the tooltip. Fades in after a configurable show delay and fades out after a hide-grace period. Press Escape to dismiss immediately.

Accessibility

  • Follows the WAI-ARIA Tooltip pattern.
  • The bubble has role="tooltip" and a unique id.
  • aria-describedby is added to the trigger element while the tooltip is open and removed when it closes.
  • The tooltip opens on mouseenter and focus; it closes on mouseleave, blur, and immediately on Escape.
  • The bubble is hoverable: moving the cursor from the trigger onto the bubble cancels the hide timer, keeping the tooltip open.
  • The tooltip is for advisory supplementary text only - never use it to convey information that is essential for the user to complete a task. Icon buttons must always have an aria-label independent of the tooltip.
