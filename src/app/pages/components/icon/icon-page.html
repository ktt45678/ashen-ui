Icon

Material Symbols Outlined icon. Use for every icon in Ashen UI - never emoji or hand-rolled SVG. Render by projecting a ligature name (<sn-icon>settings</sn-icon>) or by the icon input / .sn-icon-<name> class (codepoint mode).

Accessibility

Icons are decorative by default (aria-hidden="true"). When used standalone without a visible text label nearby, provide ariaLabel so screen readers announce the icon's meaning. The component then sets role="img" and aria-label on the host element.
