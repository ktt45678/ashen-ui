Accessibility

  • The sn-toast container carries aria-live="polite" and aria-atomic="false" so screen readers announce new toasts without interrupting the user's current reading flow.
  • Each toast card has role="status" for info and success severities, and role="alert" for warning and error - matching WAI-ARIA live-region semantics (polite vs. assertive).
  • Toasts never steal focus. They appear visually without moving keyboard focus away from the user's current position.
  • The close button has an aria-label provided by SnToastIntl.close (default: "Close notification"). Customise via provideSnIntl().
  • Hovering over a toast pauses the auto-dismiss timer; the remaining time is tracked and resumed when the cursor leaves, preventing accidental dismissal while reading.
  • All animations are suppressed when prefers-reduced-motion: reduce is set.
