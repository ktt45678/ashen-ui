Input Mask

A fixed-pattern mask for an input: phone numbers, dates, postal codes, card numbers. A directive, not a component, so it composes with snInputText, sn-form-field and Angular forms rather than replacing them.

Examples

Phone Model: {{ phone() || '(empty)' }}
Date 9 is a digit Licence plate a is a letter. Literals are anything else. ZIP ? makes everything after it optional, so 5 digits is complete.
Phone Model: {{ raw() || '(empty)' }}. The element still shows the mask.
Auto-clear time Leave the field before all six digits are entered to clear it. Retained time @if (retained.hasError('maskIncomplete')) { Angular forms reports maskIncomplete. } @else { Enter a partial value to see incomplete validation. }

API

Behaviour

  • The value holds only what you typed. The mask template is shown through the native placeholder, not written into the element. An untouched field is genuinely empty, so the floating label rests, required validation sees an empty string, and nothing has to strip _ out of your model.
  • Pasting works from any shape. (555) 123-4567, 555.123.4567 and 5551234567 all land the same way: characters that don't fit the next token are skipped rather than rejected.
  • Separators auto-advance. The third digit of (999) brings the separator with it, so the next keystroke goes where you expect.
  • Deleting a separator deletes the character in front of it. Otherwise the mask would put the separator straight back and the keypress would appear to do nothing.
  • Incomplete values follow an explicit blur policy. They clear by default or remain when autoClear is false. Angular forms receives a maskIncomplete validation error while a non-empty value is incomplete.

What this deliberately doesn't do

This masks patterns whose shape is known up front. It does not do numeric masks with thousand separators and decimals, dates that correct themselves as you type (13 → 01), masks that change shape based on input (card-type detection), or regex masks. Those are genuinely hard. Caret placement, IME composition and the browser's undo stack all fight you, and they are where a dedicated engine earns its weight.

So bring one. Maskito and imask both work on an snInputText, and neither is a dependency of this library. The only thing to wire up is what "empty" means, so the form field keeps behaving: 

{{ codeThirdParty }}

setEmptyPredicate() is public API and mask-library-agnostic: snMask is simply its first consumer.

Accessibility

  • The mask template appears as a placeholder, which assistive technology reads as a format hint rather than as a value.
  • A placeholder is not a label. Keep the sn-label.
  • The element stays a plain input, so type, inputmode, autofill hints and validation all work normally.
  • data-sn-mask-complete is for styling. Angular forms receives maskIncomplete for user-facing validation.
