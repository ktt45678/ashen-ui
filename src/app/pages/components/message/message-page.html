Accessibility

  • The host element carries role="alert" for warning and error severities, triggering an immediate screen-reader announcement. Info and success use role="status", which is a polite live region.
  • The close button has an aria-label sourced from SnMessageIntl.close (default: "Close message"). Override it with provideSnIntl({ message: { close: '…' } }).
  • When closed, the host receives .sn-message--hidden which applies display: none, removing the element from the accessibility tree.
