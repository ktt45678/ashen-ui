Paginator

Page navigation with numbered buttons, interactive ellipsis jump panel, and an Ashen-styled rows-per-page dropdown. Accepts a model-driven API - page numbers are computed from totalRecords and rows. The record report is localizable and can be replaced with a typed projected template.

Accessibility

Follows the WAI-ARIA Navigation Landmark pattern.

  • The entire widget is wrapped in a <nav aria-label> landmark. The label defaults to 'Pagination', overridable via the ariaLabel input or provideSnIntl({ paginator: '…' }).
  • The active page button has aria-current="page". All page buttons have an aria-label of the form "Page N".
  • First, Previous, Next, and Last buttons have descriptive aria-labels (overridable via firstLabel, prevLabel, nextLabel, lastLabel inputs or provideSnIntl()).
  • Navigation buttons use the native disabled attribute when at a boundary.
  • The ellipsis button has aria-haspopup="dialog" and aria-expanded toggled on open. The jump panel is role="dialog" containing a role="listbox" grid. Pressing Escape closes the panel and returns focus to the triggering ellipsis button.
  • The rows-per-page trigger has aria-haspopup="listbox" and aria-expanded. The options panel is role="listbox" with each option having role="option" and aria-selected. Pressing Escape closes the panel and returns focus to the trigger.
  • All icons are rendered in ligature mode with aria-hidden="true".
