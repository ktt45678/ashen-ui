Accessibility

  • The group host uses role="radiogroup"; each radio uses role="radio" with aria-checked.
  • Keyboard: follows the WAI-ARIA radiogroup pattern. Tab moves focus to the radiogroup (one stop). ArrowDown / ArrowRight move to the next enabled radio and select it. ArrowUp / ArrowLeft move to the previous enabled radio and select it. Arrow navigation wraps around. Space selects the focused radio.
  • Roving tabindex: only the selected radio (or the first enabled radio when nothing is selected) is focusable via Tab. All others have tabindex="-1".
  • When disabled, aria-disabled="true" is set on the group and all radios have tabindex="-1".
  • Implements ControlValueAccessor - the disabled state propagates from FormControl.disable() calls.
