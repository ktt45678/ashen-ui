Color Picker

Composable color picker with HSVA state. The default layout covers most cases; compose ColorArea, ColorSlider, ColorInput, and ColorEyeDropper children for a custom arrangement. Implements ControlValueAccessor for reactive forms and ngModel. Emits #rrggbb, or #rrggbbaa when alpha < 1.

API

Accessibility

  • ColorArea has role="slider", tabindex="0", and aria-valuetext announcing saturation and brightness. Arrow keys move in 1% steps (Shift: 10%).
  • ColorSlider has role="slider", aria-valuemin/max/now, and aria-orientation. Arrow keys and Home/End navigate the channel value.
  • ColorEyeDropper is automatically disabled when the EyeDropper API is not supported in the current browser (e.g. Firefox, Safari).
  • The popover swatch button has aria-expanded and aria-label from SnColorPickerIntl. Escape closes the overlay.
