Date Picker

An input-styled trigger that opens a calendar dialog with day, month, and year views. Click the month header to switch to a month picker; click the year to switch to a year picker. Follows the WAI-ARIA APG Date Picker Dialog pattern with roving-tabindex keyboard navigation across the grid. Implements ControlValueAccessor for reactive forms and ngModel.

API

Accessibility

  • Trigger has aria-haspopup="dialog", aria-expanded, and aria-controls pointing to the panel id.
  • Calendar panel has role="dialog" and aria-label (SnDatePickerIntl datePickerLabel or the ariaLabel input).
  • On open, focus moves into the panel: onto the selected day button, today's button, or the first day if neither is in the current view.
  • Day grid uses roving tabindex - only the focused cell has tabindex="0"; all others have tabindex="-1". This allows Tab to leave the dialog and close it.
  • Out-of-range days remain focusable with aria-disabled="true" inside a month that contains selectable dates. This exposes the boundary without allowing selection.
  • ArrowLeft / ArrowRight - move ±1 day and cross a month boundary only when the destination month contains a selectable date.
  • ArrowUp / ArrowDown - move ±7 days in the same column with the same month-boundary clamp.
  • Home / End - jump to first / last day of the current week row.
  • PageUp / PageDown - move to the same day number in the previous or next month when that month contains a selectable date. Otherwise focus remains in place.
  • Shift+PageUp / Shift+PageDown - move to the same day number in the previous or next year, subject to the same selectable-month clamp.
  • Enter / Space on a day button - picks the date, closes dialog, refocuses trigger.
  • Escape - closes the dialog without changing the value and returns focus to the trigger.
  • Tab - closes the dialog and moves focus naturally to the next focusable element.
  • Month and year grids also use roving tabindex with arrow key navigation (±1 column, ±3 row).
  • When used inside <sn-form-field>, the trigger receives the field's controlId, aria-describedby, and reports filled/unfilled state.
  • Implements ControlValueAccessor - disabled state propagates from FormControl.disable().

Theming

Internationalization

All user-facing strings come from the injectable SnDatePickerIntl service. The calendar's month and weekday names, plus the trigger's date format, are locale-aware: provide provideSnIntlLocale(locale) to derive them from Intl.DateTimeFormat automatically. Non-translatable text (button labels) can still be overridden.
