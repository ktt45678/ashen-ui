Breadcrumb

Hierarchy trail with chevron separators. Consumer writes sn-breadcrumb-item children - no data-array input required. The last item is automatically marked as the current page.

Accessibility

Follows the WAI-ARIA APG Breadcrumb pattern.

  • The navigation landmark uses <nav aria-label>. The label defaults to 'Breadcrumb' (overridable via the label input or provideSnIntl({ breadcrumb: { label: '…' } })).
  • Items are rendered in an <ol> (ordered list) reflecting the hierarchy.
  • The last item receives aria-current="page" and is rendered as a <span> (non-interactive) with pointer-events: none.
  • Non-last items with href are native <a> elements - standard browser tab/focus behavior applies.
  • Separators are wrapped in aria-hidden="true" spans so screen readers announce only the crumb labels.
