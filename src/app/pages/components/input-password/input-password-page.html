Input Password

A standalone password input component with a visibility toggle button and an optional password-strength meter. Implements ControlValueAccessor for seamless reactive forms and ngModel support. Integrates with sn-form-field.

Accessibility

  • The visibility toggle is a <button type="button"> with a dynamic aria-label - "Show password" or "Hide password" - sourced from SnPasswordIntl and overridable per-instance via showPasswordLabel / hidePasswordLabel.
  • When placed inside sn-form-field, the input's id and aria-describedby are managed automatically. aria-invalid is applied when the field is in an error state.
  • The strength meter is decorative - it uses color and a text label together so the information is conveyed to users who cannot distinguish colors.
  • The toggle is disabled alongside the input when disabled=true or setDisabledState(true) is called by forms.
