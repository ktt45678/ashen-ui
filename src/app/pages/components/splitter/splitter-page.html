Accessibility

Follows the WAI-ARIA APG Window Splitter pattern.

  • The gutter element has role="separator", tabindex="0", aria-orientation (opposite of layout: vertical gutter for horizontal layout, horizontal gutter for vertical layout), aria-valuenow, aria-valuemin, aria-valuemax, and aria-controls referencing the first panel's generated id.
  • The accessible label defaults to 'Resize panels' via SnSplitterIntl and can be overridden per-instance with resizeLabel or globally via provideSnIntl({ splitter: { resize: '…' } }).
  • Drag is implemented via pointerdown on the gutter and global pointermove/pointerup listeners attached through Renderer2.listen (SSR-safe) and detached on pointerup.
