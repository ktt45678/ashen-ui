Accessibility

Follows the WAI-ARIA APG Tabs pattern with automatic activation (selection follows focus).

  • The tab list has role="tablist". Each tab button is a native <button type="button" role="tab"> with aria-selected, aria-controls pointing to the panel id, and roving tabindex (0 for active, -1 for others).
  • The active content panel has role="tabpanel", tabindex="0", and aria-labelledby pointing to the active tab button's id.
  • Inactive panels are removed from the DOM (not merely hidden), keeping the accessibility tree clean and panel content lazily instantiated.
  • Disabled tabs receive the native disabled attribute on their button and are skipped by keyboard navigation.
  • The sliding indicator is purely decorative (aria-hidden="true"); the active aria-selected attribute on the button communicates selection state to assistive technology.
  • SSR note: The indicator's geometry is measured from the DOM via afterNextRender and a signal effect - both run only in the browser, so a server-rendered or prerendered app does not attempt DOM measurement and the indicator is not rendered server-side. On first client render it appears immediately without layout shift.
