Toggle Button

A native <button> that reflects a pressed/unpressed state via aria-pressed. Fills primary when selected and takes an input-styled appearance when unselected. Implements ControlValueAccessor so it works with reactive forms and ngModel. Icons and labels are projected content.

Accessibility

  • Uses a native <button> with type="button" - inherits native semantics, keyboard focus, and activation for free.
  • aria-pressed is set to true or false to reflect the pressed state per the WAI-ARIA button pattern.
  • Keyboard: Space and Enter toggle the state; Tab moves focus normally (native button behavior).
  • When disabled, the native disabled attribute is set, removing the element from tab order and preventing all interaction.
  • For icon-only buttons, add aria-label directly on the host element to provide an accessible name.
  • Implements ControlValueAccessor - the disabled state propagates from bound FormControl.disable() calls.
