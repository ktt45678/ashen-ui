Toggle

A pill-track switch for boolean options. The track fills the primary color when on and the thumb slides to indicate state. Implements ControlValueAccessor so it works with reactive forms and ngModel. The label is projected content - omit it for an unlabelled switch.

Accessibility

  • Uses role="switch" on the host element with aria-checked set to true or false to reflect the on/off state.
  • Keyboard: Space and Enter toggle the switch state. Tab moves focus normally.
  • When disabled, tabindex="-1" removes the element from tab order and aria-disabled="true" is set.
  • The label is projected content - wrap in aria-label on the host for icon-only or visually hidden labels.
  • Implements ControlValueAccessor - the disabled state propagates from bound FormControl.disable() calls.
