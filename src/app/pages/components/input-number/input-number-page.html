Input Number

Directive on a native <input type="number"> element that applies Ashen UI styling and wires into the surrounding sn-form-field. Supports min/max/step constraints with automatic clamping on blur. Form bindings use Angular's built-in number value accessor - no wrapper needed.

Accessibility

  • Uses a native <input type="number"> element - all browser and assistive technology semantics are preserved without any wrapper.
  • When placed inside sn-form-field, the id, aria-required, and aria-describedby attributes are managed automatically via the SN_FORM_FIELD DI context (inherited from InputText).
  • aria-invalid="true" is applied when the invalid input is true or when a bound FormControl is invalid and has been touched or dirtied.
  • On blur, if the value falls outside the [min]/[max] range it is automatically clamped and an input event is dispatched so Angular forms pick up the corrected value.
