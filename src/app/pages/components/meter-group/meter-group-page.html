Accessibility

  • Each bar segment carries role="meter" with aria-valuenow, aria-valuemin="0", and aria-valuemax set to the group's max value, per the WAI-ARIA meter role guidance.
  • Each segment's aria-label is set to the meter's label input, identifying the segment for screen readers.
  • Set the label input on sn-meter-group to provide an aria-label for the whole measurement group (e.g. "Storage usage").
  • Segment width transitions are disabled when prefers-reduced-motion: reduce is set.
  • The sn-meter elements themselves are hidden via display: none - they are data-holder components; all visual structure is rendered by the parent.
