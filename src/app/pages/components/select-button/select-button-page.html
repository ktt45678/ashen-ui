Select Button

A toggle-button group that supports single and multiple selection. Renders native <button> elements projected by the consumer - no options array input. Implements ControlValueAccessor for reactive forms and ngModel.

Accessibility

  • The container has role="group". When disabled, aria-disabled="true" is also set.
  • Each option is a native <button type="button"> with aria-pressed reflecting its selected state.
  • Navigation uses the browser's natural Tab order - each enabled button is individually focusable. Space and Enter activate the focused button for free via native button behavior.
  • Disabled options receive the native disabled attribute so they are excluded from the tab order automatically.
  • Focus ring is visible via :focus-visible with a primary-color outline.
  • Implements ControlValueAccessor - the disabled state propagates from bound FormControl.disable() calls.
