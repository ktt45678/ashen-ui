Tree Table

Hierarchical rows in a table shell. The first column carries the expand toggle and optional node icon; other columns display data fields. Implements the WAI-ARIA APG Treegrid pattern (row-focus subset) with roving tabindex keyboard navigation.

API

Accessibility

  • Implements the WAI-ARIA APG Treegrid pattern - row-focus subset.
  • The inner <table> carries role="treegrid" and aria-label. Native table semantics are intentionally overridden by this role.
  • Each visible row is a role="row" <tr>. The DOM is flat (no nested groups); positional context is conveyed via aria-level, aria-setsize, and aria-posinset.
  • Parent rows carry aria-expanded="true" or "false". Leaf rows have no aria-expanded.
  • Focus is managed with roving tabindex: exactly one row has tabindex="0" at any time; all others are tabindex="-1".
  • When the active row is hidden (e.g. its parent is collapsed), focus moves to the collapsed ancestor.
  • The expand toggle is a real <button type="button" tabindex="-1"> with an aria-label of "Expand" / "Collapse" from SnTreeIntl.
  • Row selection is intentionally absent - the design export has no selection affordance. Rows are navigable but not selectable.
  • Column headers use scope="col" for correct cell association.

Keyboard map

KeyAction
ArrowDownMove focus to the next visible row.
ArrowUpMove focus to the previous visible row.
ArrowRightCollapsed parent: expand it. Expanded parent: move focus to first child row. Leaf: no-op.
ArrowLeftExpanded parent: collapse it. Leaf or collapsed node: move focus to parent row (if any).
HomeMove focus to the first visible row.
EndMove focus to the last visible row.

Note: Enter and Space have no action - row selection is not part of this component. This matches the design export which has no selection affordance.
