AutoComplete

A text input with a live-filtered suggestion panel. As you type the panel narrows to matching suggestions; picking one fills the input. Free text is always accepted - selection is optional. Implements the WAI-ARIA APG Combobox with list autocomplete pattern using aria-activedescendant. Implements ControlValueAccessor for reactive forms and ngModel.

API

Accessibility

  • Follows the WAI-ARIA APG Combobox with list autocomplete pattern. The input has role="combobox", aria-autocomplete="list", aria-expanded, and aria-controls.
  • Focus stays on the input at all times. aria-activedescendant tracks the highlighted option using its generated id.
  • ArrowDown - open panel (if closed) or move active option down (clamped, no wrap).
  • ArrowUp - move active option up (clamped, no wrap).
  • Enter - pick the active option if one is highlighted; otherwise do nothing (allows form submit).
  • Escape - close the panel without changing the value.
  • Tab - close the panel and move focus to the next element normally.
  • Home / End intentionally left to native input text-caret behavior - the APG combobox pattern with list autocomplete requires this so users can navigate within the typed text.
  • In multiple mode, Backspace removes the last selected value only when the input query is empty. Each visible value also has a localized remove button, unless removable is off.
  • In multiple mode aria-selected reports the values actually selected, since selected suggestions stay in the panel. In single mode it follows the active option, as the APG combobox pattern specifies.
  • Implements ControlValueAccessor - disabled state propagates from FormControl.disable().
