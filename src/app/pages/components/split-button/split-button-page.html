Split Button

A composite of a primary action button and a chevron trigger that opens a sn-menu of related secondary commands. Reuses Button and MenuTrigger wholesale - no reimplementation of overlay or keyboard logic.

Accessibility

  • The trigger button receives aria-haspopup="menu", aria-expanded, and aria-controls automatically via the MenuTrigger directive (APG Menu Button pattern).
  • Keyboard: Enter, Space, or ArrowDown on the trigger opens the menu and focuses the first item; ArrowUp focuses the last item. Escape closes and returns focus to the trigger.
  • The trigger's accessible name defaults to 'More actions' (via SnSplitButtonIntl.more) and can be overridden with dropdownAriaLabel or globally via provideSnIntl({ splitButton: { more: '…' } }).
  • When disabled, native disabled attributes are set on both buttons so browsers block interaction and screen readers announce the state.
