Table

Dense bordered data table with uppercase header row, optional column sorting, row stripes, hover, single/multi selection, row expansion, pagination, virtual/infinite scroll, and drag-and-drop reordering. Columns are projected as sn-column elements; rows come from the value input array.

Accessibility

  • Follows the APG Sortable Table pattern.
  • Sort triggers are real <button type="button"> elements inside <th> - never a clickable header cell.
  • aria-sort="ascending" / "descending" is set on the <th> of the sorted column; absent when not sorted.
  • When selectable is true, body rows have tabindex="0" and respond to Enter and Space.
  • In selectionMode="multiple", the header checkbox uses aria-label for "select all" and body checkboxes for "select row".
  • The expand chevron has aria-expanded and aria-controls pointing to the expansion row.
  • In layout="flex", explicit role="table", role="row", and role="cell" attributes are added for screen-reader compatibility.
  • Column headers use scope="col" for correct cell association by screen readers.
