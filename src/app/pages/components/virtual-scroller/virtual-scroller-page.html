Virtual Scroller

Windowed rendering for very large lists - only the rows currently visible (plus a small buffer) are mounted in the DOM. Backed by Angular CDK's fixed-size virtual scroll strategy, so every row must have the same height in pixels.

Rows scrolled out of view are removed from the DOM and re-rendered when you scroll back - the total scroll height is preserved so the position never jumps. Near the end, loadMore fires to append the next page.
