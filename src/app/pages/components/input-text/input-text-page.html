Input Text

Directive on a native <input> element that applies Ashen UI styling and wires into the surrounding sn-form-field. Supports reactive forms and template-driven forms natively - no wrapper component.

Accessibility

  • Uses a native <input> element - all browser and assistive technology semantics are preserved without any wrapper.
  • When placed inside sn-form-field, the id, aria-required, and aria-describedby attributes are managed automatically via the SN_FORM_FIELD DI context.
  • aria-invalid="true" is applied when the invalid input is true or when a bound FormControl is in an invalid state and the user has interacted with the field (touched or dirty).
  • disabled and readonly states are handled entirely by native HTML attributes - no Angular wrapping is needed.
