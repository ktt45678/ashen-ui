Tab Nav

A row of navigation links styled as tabs, for pages where each tab is a URL. Unlike sn-tabs it owns no panels: the router outlet shows the content.

Accessibility

Tab Nav is a navigation landmark, not an ARIA tablist. Its links move between pages, so it follows the navigation pattern rather than the tabs pattern. Use sn-tabs when the tabs switch panels on the same page.

  • Put it on a <nav> and give it an aria-label when the page has more than one navigation landmark.
  • The active link gets aria-current="page" on an <a> and aria-current="true" on a <button>.
  • Every link stays in the tab order, and Tab moves between them. There is no arrow-key roving focus, because these are links, not tabs.
  • The scroll controls are hidden from assistive technology and skipped by the keyboard. Focusing a link scrolls it into view, so they are a pointer convenience only.
