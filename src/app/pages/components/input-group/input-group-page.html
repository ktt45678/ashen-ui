Accessibility

  • sn-input-group sets role="group" on the host so screen readers announce the grouping relationship between addons and the control.
  • Icon addons render with aria-hidden="true" because they are decorative; ensure the associated input has a visible label or aria-label.
  • Button addons receive focus in normal tab order; give them a descriptive accessible name (visible text or aria-label).
  • Wrap the group inside sn-form-field to get automatic label association, aria-describedby for hints/errors, and aria-required/aria-invalid propagation to the input.
