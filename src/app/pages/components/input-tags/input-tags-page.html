Input Tags

A CVA component that renders a flex-wrap shell containing removable sn-chip elements and a borderless text input. Typing then pressing Enter or , adds the text as a tag; Backspace on an empty field removes the last tag. Works with reactive forms, ngModel, and the two-way [(value)] binding.

Keyboard & Accessibility

KeyBehaviour
EnterAdds the current text as a tag (trimmed; ignores empty or duplicate).
,Same as Enter - adds the current text as a tag.
BackspaceWhen the text input is empty, removes the last tag.
Tab / blurCommits any pending text as a tag, then calls onTouched.
  • Each tag is rendered as a sn-chip with a remove button that carries an aria-label of the form "Remove <tag>" (resolved via SnChipIntl.remove).
  • The internal <input> receives id, aria-describedby, and aria-invalid from the surrounding sn-form-field when present.
  • Clicking anywhere on the shell focuses the text input, keeping the interaction area large.
