Accessibility

Follows the WAI-ARIA APG Accordion pattern.

  • Each section header is a native <button type="button"> inside a <h3> element. The button carries aria-expanded reflecting the current state and aria-controls pointing to the content region's id.
  • The content region has role="region" and aria-labelledby pointing to the header button's id, forming an accessible landmark.
  • When collapsed, the content div is removed from the DOM (not just hidden), keeping the accessibility tree clean.
  • Disabled panels receive the native disabled attribute on their button; they cannot be toggled and are skipped by the keyboard focus manager.
  • The default chevron icon is decorative; the button's text content provides the accessible name.
