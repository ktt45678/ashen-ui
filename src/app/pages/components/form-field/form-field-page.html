Form Field

Wrapper that pairs a label, a form control, and optional hint or error text. Associates label and control via for/id and wires aria-describedby to hint and error regions automatically. All regions are separate sub-components projected by the consumer.

Accessibility

  • The <label> element inside sn-label has its for attribute wired to the control's id automatically via the SN_FORM_FIELD DI context - no manual id management needed.
  • When required is set on sn-label, the child input[snInputText] receives aria-required="true" automatically.
  • The control's aria-describedby lists all registered hint and error ids, updated whenever sn-hint or sn-error elements are added or removed (e.g. via @if). Multiple errors and multiple hints are all included simultaneously.
  • Each sn-error renders a role="alert" element, which triggers a live-region announcement when the error appears.
  • The * required indicator is marked aria-hidden="true" - the label text and aria-required convey the requirement to assistive technology without duplicating it.
