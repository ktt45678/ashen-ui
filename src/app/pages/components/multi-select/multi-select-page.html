Multi Select

A multi-value dropdown that shows selected options as removable chips in the trigger and checkbox rows in the panel. Implements the WAI-ARIA APG Combobox with multi-select listbox popup - focus stays on the trigger while aria-activedescendant tracks the highlighted option. Reuses <sn-list-option> children from ashen-ui/listbox. Implements ControlValueAccessor for reactive forms and ngModel.

API

Accessibility

  • Follows the WAI-ARIA APG Combobox with listbox popup pattern with multi-select.
  • The panel has role="listbox" and aria-multiselectable="true". Each option has role="option" and aria-selected.
  • Focus stays on the trigger while the panel is open. aria-activedescendant tracks the highlighted option.
  • Enter / Space toggle the active option and keep the panel open - unlike single Select where they close.
  • Escape closes the panel without changing the selection. Tab closes and moves focus naturally.
  • Chip remove buttons include an accessible aria-label via SnChipIntl.remove. Clicking a chip or its container does NOT open/close the panel (stopPropagation).
  • Implements ControlValueAccessor - disabled state propagates from FormControl.disable().
