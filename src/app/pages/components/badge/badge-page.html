Accessibility

  • Standalone badges carry role="status" so screen readers announce updates without interrupting the user.
  • The aria-label attribute is set to the value string on standalone badges, giving an accessible name without relying on visual text.
  • Overlay badges hide the inner pip with aria-hidden="true"; the badge information should be communicated through the labelling on the wrapped element (e.g. aria-label="Notifications - 2 unread" on the button).
