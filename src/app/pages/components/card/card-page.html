Card

An elevated panel container: a soft shadow, no outline, 8 px radius. Set --sn-card-border-color for the outlined variant. Compose sn-card-header, sn-card-title, sn-card-subtitle, sn-card-content, and sn-card-footer inside sn-card - include only the regions you need.

Accessibility

  • sn-card renders as a plain div with no implicit ARIA role. Add role="region" and an aria-label or aria-labelledby when the card represents a landmark section.
  • sn-card-title does not render an HTML heading element by default. Project an <h2> (or appropriate level) inside sn-card-title when semantic heading structure is required.
  • Each sub-component is a standalone element - they can be imported and used independently without the others.
