Infinite Scroll

Attach snInfiniteScroll to any scrollable element (or the window) to receive scrolled / scrolledUp events as the user approaches either edge. Uses IntersectionObserver sentinels - no scroll-event polling. SSR-safe.

Sentinel mechanism. The directive inserts a 1 px div at the top and bottom of the host element. Angular's @for block content lands between the sentinels automatically, so new items always sit above the bottom sentinel. When the list is shorter than the viewport, the bottom sentinel is visible immediately - scrolled fires on mount, letting consumers auto-fill short lists. The top sentinel is suppressed until the container has actually scrolled to prevent a spurious scrolledUp on initial render.

API

Accessibility

snInfiniteScroll adds no ARIA attributes. Announce newly loaded content to screen readers with an aria-live region or an aria-label update on the list container. Provide a manual "Load more" button as a keyboard fallback so users who cannot scroll (switch access, keyboard-only) can still access paginated content.
