Tag

Small rectangular category label - soft severity tint with colored text. Use to denote status, category, or metadata. 4 px corner radius differentiates it from the pill-shaped Chip.

Accessibility

  • Tags are inline passive labels - they carry no interactive role or keyboard behavior.
  • Color is used for visual emphasis but is never the only indicator; the text value always provides the semantic meaning.
  • The leading icon is marked aria-hidden="true" so it is not read twice by screen readers.
