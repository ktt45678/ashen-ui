Slider

A range input component that wraps a native <input type="range"> with decorative fill and thumb overlays. All keyboard interaction (arrow keys, Home, End, Page Up/Down) and pointer drag are handled by the browser. Integrates with Angular reactive forms and template-driven forms.

Accessibility

  • Uses a native <input type="range"> - the browser provides role="slider", aria-valuenow, aria-valuemin, aria-valuemax, and full keyboard support (arrow keys, Home, End, Page Up / Down) for free without any custom logic.
  • When formatValue is provided, aria-valuetext is set so screen readers announce the human-readable label (e.g. "50%" or "$25.00") instead of the raw number.
  • When placed inside sn-form-field, the id and aria-describedby are wired automatically via the SN_FORM_FIELD DI context so the label and hints are associated with the control.
  • The decorative fill and thumb elements are pointer-events: none so they never intercept interaction; the transparent overlay range input is the sole interactive element.
  • A focus ring appears on the thumb via :focus-within on the track, keeping the visual indicator close to the draggable point.
  • The thumb tracks the value instantly (no position transition), so the thumb and fill never drift apart during a drag.
