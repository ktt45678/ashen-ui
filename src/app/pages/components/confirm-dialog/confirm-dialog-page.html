Confirm Dialog

A small modal confirmation preset built on Dialog. Presents an icon, a message, and reject/accept buttons. Use severity="error" with a contextual icon for destructive actions; the severity drives both the icon color and the accept button color.

Prefer to trigger a confirmation from code? Inject DialogService from ashen-ui/dialog and call dialog.confirm({{ '{' }} message, severity {{ '}' }}).subscribe(ok => …): it resolves to true when accepted and false when rejected or dismissed. See the Dialog page for the full imperative API.

Accessibility

  • The underlying sn-dialog panel carries role="dialog", aria-modal="true", and aria-labelledby pointing to the title element. WAI-ARIA APG recommends role="alertdialog" for confirmations; the underlying Dialog uses role="dialog" - document this if your app requires strict alertdialog semantics, but do not fork Dialog.
  • Focus is trapped within the panel on open (CDK ConfigurableFocusTrapFactory) and returned to the triggering element on close.
  • Escape, backdrop click, and the close button all close the dialog and emit the reject output.
  • Body scroll is blocked while the dialog is open (CDK BlockScrollStrategy).
  • Use a clear, action-specific acceptLabel (e.g. "Delete" instead of "Yes") so screen reader users understand the consequence before confirming.
