Dialog

A centered modal panel rendered over a dark backdrop. Use Dialog for confirmations, form editing, and contextual actions that require the user's full attention before continuing. The dialog traps focus, blocks body scroll, and closes on Escape, backdrop click, or the built-in close button.

Accessibility

  • Follows the WAI-ARIA Modal Dialog Pattern. The panel has role="dialog", aria-modal="true", and aria-labelledby pointing to the title element.
  • Focus moves into the first focusable element in the panel on open (via CDK ConfigurableFocusTrapFactory).
  • Focus is trapped within the dialog - Tab cycles through the panel's focusable elements and cannot reach elements behind the backdrop.
  • Focus returns to the element that had focus before the dialog opened.
  • Escape closes the dialog and restores focus.
  • Clicking the backdrop closes the dialog (CDK backdropClick() subscription).
  • Body scroll is blocked while the dialog is open (CDK BlockScrollStrategy).
  • The close button's aria-label defaults to 'Close' (overridable via closeLabel input or provideSnIntl()).
