Checkbox

A standalone checkbox control with checked, indeterminate, and disabled states. Implements ControlValueAccessor so it works with reactive forms and ngModel. The label is projected content - omit it for an unlabelled checkbox.

Accessibility

  • Uses role="checkbox" on the host element with aria-checked set to true, false, or "mixed" (for indeterminate).
  • Keyboard: Space and Enter toggle the checked state. Tab moves focus normally.
  • When disabled, tabindex="-1" removes the element from tab order and aria-disabled="true" is set.
  • The label is projected content - wrap in aria-label on the host for icon-only or visually hidden labels.
  • Implements ControlValueAccessor - the disabled state propagates from bound FormControl.disable() calls.
