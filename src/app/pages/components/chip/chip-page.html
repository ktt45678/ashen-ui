Chip

Compact entity pill - hover surface fill, primary tint when selected, optional leading icon and removable × button. Suitable for tags, filter selections, and keyword sets.

Accessibility

  • Chips have tabindex="0" and can receive keyboard focus. When removable, the Backspace and Delete keys fire the removed output while the chip is focused.
  • The remove button has an aria-label of "Remove <label>" so screen readers announce its purpose.
  • The leading icon and the close icon are marked aria-hidden="true" to avoid duplicating the label in screen reader output.
  • When building chip input or filter groups, wrap the chips in a role="group" container with an accessible name to give screen reader users context.
