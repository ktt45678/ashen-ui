Panel

A bordered section container with a header row (icon, title, actions) and an optional collapse toggle. Use it to group related settings or content that may be shown or hidden.

Accessibility

  • Follows the WAI-ARIA Disclosure (Show/Hide) pattern. The toggle is a native <button type="button"> with aria-expanded reflecting the current state and aria-controls pointing at the content region's id.
  • The toggle's aria-label switches between the expandLabel and collapseLabel values so screen readers announce the action.
  • When collapsed, the content wrapper receives the inert attribute, removing it from the accessibility tree while keeping it in the DOM for smooth animation.
  • The default chevron icon has aria-hidden set by the icon component - it is purely decorative; the toggle's aria-label provides the accessible name.
  • The toggle button has a visible :focus-visible ring styled with --sn-focus-ring-* tokens.
