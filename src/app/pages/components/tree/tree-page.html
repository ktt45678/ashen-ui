Tree

Hierarchical node list with chevron expand/collapse and single-row selection. Nodes are supplied as a data array; children are revealed on expand. Implements the WAI-ARIA APG TreeView pattern with roving tabindex keyboard navigation.

API

Accessibility

  • Implements the WAI-ARIA APG TreeView pattern.
  • The host element carries role="tree" and aria-label.
  • Each visible node is a role="treeitem" div. The DOM is flat (no nested role="group"); positional context is conveyed via aria-level, aria-setsize, and aria-posinset.
  • Parent nodes carry aria-expanded="true" or "false". Leaf nodes have no aria-expanded.
  • All nodes carry aria-selected="true" or "false" (single-select tree).
  • Focus is managed with roving tabindex: exactly one node has tabindex="0" at any time; all others are tabindex="-1". Moving focus programmatically calls .focus() on the target element.
  • When the active node is hidden (e.g. its parent is collapsed), active focus moves to the collapsed ancestor.
  • The expand/collapse chevron is a real <button type="button" tabindex="-1"> with an aria-label of "Expand" / "Collapse".

Keyboard map

KeyAction
ArrowDownMove focus to the next visible node.
ArrowUpMove focus to the previous visible node.
ArrowRightCollapsed parent: expand it. Expanded parent: move focus to first child. Leaf: no-op.
ArrowLeftExpanded parent: collapse it. Leaf or collapsed node: move focus to parent (if any).
HomeMove focus to the first visible node.
EndMove focus to the last visible node.
Enter / SpaceSelect the focused node.

Note: Typeahead (jump to node by first character) is intentionally omitted from this implementation. It can be added as a future enhancement.
