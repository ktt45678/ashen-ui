Avatar

A user or entity thumbnail. Image, initials and icon are a fallback chain, so a broken URL degrades to initials rather than to a blank circle.

Theming

Accessibility

  • With an image, the img carries the alt text and the host stays unlabelled, so the person is announced once.
  • Without an image, the host takes role="img" and an aria-label from alt or label. An avatar with neither is silent, which is right for a decorative placeholder.
  • The icon is aria-hidden; it is decoration on top of the host label.
  • The group's counter is role="img" labelled "3 more", resolved through SnAvatarIntl so it can be translated: provideSnIntl({ avatar: { more: (n) => `${n} khác` } })
