Skeleton

Loading placeholder with shimmer or pulse animation - use while content is being fetched to reduce perceived latency. Supports text line, rect, circle, and grid-tile shapes.

Accessibility

  • Skeleton placeholders are decorative and carry aria-hidden="true" so screen readers skip them entirely while content is loading.
  • For a region that is actively loading, wrap the skeleton group in a container with aria-busy="true" and aria-label (e.g. "Loading content") so assistive technology can announce the loading state to users. Remove the attribute when real content replaces the skeletons.
  • The shimmer and pulse animations are suppressed automatically when the user's system has prefers-reduced-motion: reduce enabled, matching the same motion tokens used throughout the library.
