Cascade Select

A Select-style trigger that opens a nested option tree with flyout submenus. Hover a parent row to reveal its children; click a leaf to select its value. Follows the WAI-ARIA combobox + tree popup pattern with activedescendant keyboard navigation. Implements ControlValueAccessor for reactive forms and ngModel.

API

Accessibility

  • Trigger has role="combobox", aria-haspopup="tree", aria-expanded, aria-controls pointing to the panel id, and aria-activedescendant reflecting the keyboard-active option while open.
  • The root panel has role="tree"; each option row has role="treeitem". Parent rows carry aria-expanded; selected leaves carry aria-selected="true".
  • Focus stays on the trigger (activedescendant pattern) - no focus moves into the flyout tree.
  • Trigger - closed: Enter, Space, ArrowDown, ArrowUp open the panel and move the active item to the first root option.
  • ArrowDown / ArrowUp - move within the current level (clamped, no wrap).
  • ArrowRight - on a parent: opens its flyout and moves active to its first child.
  • ArrowLeft - when inside a flyout: moves active back to the parent and closes the flyout.
  • Home / End - jump to first / last option at the current level.
  • Enter / Space - on a leaf: picks the value and closes. On a parent: toggles the flyout.
  • Escape - closes the panel without changing the value and returns focus to the trigger.
  • Tab - closes the panel and moves focus naturally to the next focusable element.
  • Mouse hover - hovering a parent opens its flyout; hovering another option closes siblings.
  • When used inside <sn-form-field>, the trigger receives the field's controlId and reports filled/unfilled state.
  • Implements ControlValueAccessor - disabled state propagates from FormControl.disable().
