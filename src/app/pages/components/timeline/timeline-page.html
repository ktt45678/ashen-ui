Timeline

Vertical chain of events with dot or icon markers, connector lines, and projected content. Use to display an ordered history of actions, states, or log entries.

Examples

Grid created 09:12 Tile added 09:14
Play Music → play-sound
 Action run 09:41 Draft saved Review started Published Awaiting approval Approved Rejected

API

Theming

Accessibility

  • The timeline renders as an <ol> list; each item has role="listitem".
  • The axis (marker + connector) column is aria-hidden="true" - decorative.
  • Icon ligatures inside markers carry no semantic meaning and are hidden from AT.
  • Timeline items are passive - no keyboard interaction is added.
