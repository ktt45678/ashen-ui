Progress Spinner

SVG ring spinner - indeterminate by default; pass value for a determinate arc. A variant="material" option renders the Material 3 style with rounded caps, gapped track, and a grow/shrink indeterminate arc.

Accessibility

  • The host element carries role="progressbar" with aria-valuemin="0" and aria-valuemax="100".
  • In determinate mode, aria-valuenow reflects the current value; the SVG is marked aria-hidden="true" to prevent double-reading.
  • In indeterminate mode, aria-valuenow is omitted; the host receives an aria-label from the ariaLabel input or the SnCommonIntl.loading string ("Loading" by default).
  • Animations are paused when prefers-reduced-motion: reduce is set.
